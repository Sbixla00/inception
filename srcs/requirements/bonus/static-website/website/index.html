About This Project

This is a complete Docker-based infrastructure project implementing a WordPress website with multiple services, each running in isolated containers.

Services Running

🌐

Nginx

Web server with TLS/SSL (HTTPS only)

⚡

WordPress + PHP-FPM

Content management system

🗄️

MariaDB

Database server

⚡

Redis

Cache server for performance

📁

FTP Server

File transfer with FTPS

📊

Adminer

Database management UI

🐳

Portainer

Docker management interface

📄

Static Website

This page! (No PHP)

Technologies Used

Docker Docker Compose Alpine Linux Nginx PHP-FPM MariaDB WordPress Redis vsftpd TLS/SSL

Container Isolation

🔒 Namespaces

  • PID: Process isolation
  • Network: Isolated network stack
  • Mount: Filesystem isolation
  • UTS: Hostname isolation

⚙️ Cgroups

  • CPU: CPU usage limits
  • Memory: RAM allocation
  • I/O: Disk bandwidth
  • Network: Network bandwidth
